# 小編萬聖夜（山頂國小）

山頂國小同人小遊戲，玩法照參考影片（Last Extract 類的「直式校舍剖面生存」）：萬聖節晚會前，南瓜仔佔領了校舍。玩家是**小編**，在一層一層切開的校舍裡走來走去、爬梯子上下樓，**攻擊全自動**；打怪掉糖果升級，**三選一挑技能**；每關找齊 3 樣晚會要用的東西，再回撤離點撐過倒數（老師開門）。第 5 關頂樓有南瓜大王。免費、不用登入，沒有儲值、等待、廣告復活。

**線上玩：** https://pokemonida99.github.io/bian-halloween/（repo pokemonida99/bian-halloween，GitHub Pages 從 main 根目錄）

- 開啟：上層 `.claude/launch.json` 的 `bian-halloween`（`python3 bian-halloween/tools/serve.py 4530`，開發用、不快取），手機連同一個 Wi‑Fi 開 `http://<電腦IP>:4530/`
- 直式手機為主（畫面寬 600 單位塞滿螢幕寬）；橫的螢幕看 860 單位高、介面放中間 720 那一欄
- 兔兔老師只在劇情出現（開場、撤離點、過關）；校長平常也只在劇情，**除非抽到「針筒超人」卡**：校長先走出來，變身針筒超人飛來飛去撞怪 20 秒，變回校長跟在旁邊休息 20 秒，再變身，一直輪流（v1.1 使用者要求；原本 v1.0 使用者說不放針筒，後來自己改要這張卡）
- 武器都是學校的東西（v1.1 使用者要求），**標稀有度**（v1.3）：
  - 普通（灰綠）：粉筆連發、體育哨子（定住周圍）、拖地水桶（地板濕濕的變慢）、電風扇（身邊吹風變慢）、圖釘（撒在地上）、板擦（一團粉筆灰）
  - 稀有（藍）：跳繩（繞身體轉）、躲避球、竹掃把（揮過一整排）、扯鈴（兩根棍子＋線拉著，拋到怪多的地方落地狂轉、把怪捲進來再拉回來）、直笛（前方音波震退）、針筒超人
  - 史詩（紫）：紙飛機（隨機俯衝）、籃球（在怪之間彈來彈去）、呼拉圈（一圈圈擴散推開）
  - 稀有度越高越少出現（`RARE` 的權重）；被動道具（書包護盾、室內鞋、營養午餐、乖寶寶印章、上課鐘）標「道具」、不佔格子
- **武器最多帶 5 種**（`MAXW`）：滿了還是會抽到新武器（卡片寫「要換掉一種」），選了要挑一種丟掉，或放棄這張（補 20 血）
- 校長台詞（`HERO_LINES`）：休息時每 7 秒抽一次、六成會講（多半問「那個影片做好了嗎？」），變身喊「變身！」，變回來喊「打針好痛😭」
- 糖果要走到 200 px 內才會飛過來（v1.3，原本掉出來 0.45 秒後全部自動飛過來）；被怪碰到的判定放寬（半徑多 14、無敵 0.36 秒）
- 第 2 關：拿齊 3 樣後，**床單鬼王**出現在撤離點（會穿牆、每 7 秒叫 3 隻床單鬼），打倒才開始撤離倒數 20 秒；第 5 關的南瓜大王還是在頂樓（`LEVELS[].boss = { k, at: 'exit' | 'roof' }`）
- **存檔與選關**：選關每一關都能直接玩（過關的會標「過關・最快幾分」）；打到一半每 5 秒自動存、暫停回選單或跳出 App 也會存，標題畫面按「繼續」接著玩（localStorage `bian-halloween-run`，過關、失敗、重來就清掉）；過關紀錄在 `bian-halloween`

## 片頭與配樂（v1.2）

- 配樂是使用者給的歌（Suno 做的純音樂，原檔 Opus，iPhone 不一定能播，轉成 AAC 128k、剪掉開頭 0.35 秒靜音 → `music/bgm.m4a`）
- 瀏覽器要先點一下才給出聲音：載入完停在「點一下開始」，點了才播片頭＋歌（Android 順便進全螢幕）
- 片頭約 6 秒、跟歌對拍：夜空往下搖到校舍 →1.58 秒（歌的第一個重拍）南瓜仔、蝙蝠衝過去 →3.24 秒片名砸下來（位置跟標題畫面一樣，結束直接接上標題）。點畫面或「跳過」直接到標題；標題右上「再看一次片頭」。有聲音時照歌的播放時間走（`SND.songTime()`），所以不會跑掉
- 測試：`?noop` 不播片頭直接到標題（`?bot` 也是）

## 操作

- 手指按住畫面任何地方拖曳＝搖桿（底座跟著手指走）；電腦 WASD／方向鍵
- 走到梯子旁往上推（或往下推）就爬；梯子附近會出現粉筆箭頭
- 站在任務物品旁 2 秒（黃色進度圈）才拿得到；南瓜寶箱碰到就送一張卡
- 升級卡出現後 0.35 秒內點不算（避免手指還在拖搖桿誤點）；電腦可按 1／2／3

| `js/data.js` | **所有數值**：怪物、14 種技能（每種 5 級）、5 關佈局與出怪、劇情台詞 |

### 校舍與怪物

- 一間教室 600×400、樓板 40；`rooms` 由上到下寫每層的教室種類，`ladders [樓層, 欄]` 是往上一層的梯子（欄 0.5＝第一間正中）
- 地上的怪（南瓜仔、木乃伊）：同一層就走向小編，到身邊停下來咬；不同層就走到最近的梯子（或外牆，比較遠）爬上爬下
- 疊成一坨：前面被同伴擋住會往上跳，互推時上面那隻往上擠，重力拉回來 → 像影片那樣一坨一坨；**爬梯子的不參與互推**（會被推出天花板卡住，修過）
- 會飛的（蝙蝠、床單鬼）直接穿樓板飛過來
- 出怪：六成生在同一層、剛好在畫面外，一次一小群；每隔一段時間從遠的那一邊來一大群；拿齊 3 樣再來一大群
- 小編被擠住會走很慢（前面有一坨地上的怪）；被打到 0.4 秒無敵（被圍住是一下一下扣）
- 傷害數字：同一隻怪 0.3 秒內的傷害加總成一個數字

### 平衡

```
node tools/sim.js            # 每關 8 個亂數種子，機器人照常見玩法挑卡
PICK=random SEEDS=12 node tools/sim.js   # 亂選卡
node tools/sim.js 5          # 只跑第 5 關
```

目前（v1.3，使用者說扣血太少後調難）：照常見玩法挑卡 8 次過關 8／7／7／6／4（第 1～5 關），亂選卡 12 次過關 12／7／9／8／8。機器人會順路撿同一層 320 px 內的糖果。機器人走最短路線，真人通常要再久一點（一關約 2～4 分鐘）。調難度主要改 `data.js` 的 `waves`（rate 每秒幾隻、grow 每分鐘加多少、cap 上限、horde 大群）和 `core.js` 的 `hpMul`（怪隨時間變耐打）。

### 測試

- `?bot`：自動玩、自動選第一張卡、劇情自動跳過
- 主控台 `G.start(關卡 0～4)`、`G.ff(秒)` 快轉（不畫畫面）、`G.run(秒)` 手動跑畫面（預覽視窗藏起來時 requestAnimationFrame 不會跑）、`G.win()` 直接過關、`G.give('glow', 5)` 給技能、`G.prof()` 量一格多久

## 美術

方向：山頂國小系列的黑板、粉筆、作業簿紙，加萬聖節的南瓜橘與夜色。字型霞鶩文楷 TC。不用粉彩漸層、大圓角、emoji 圖示。

- 教室背景 9 張（娃娃屋剖面、夜晚、孩子做的萬聖節布置）、夜空、怪物 5 種、物品圖示表、技能圖示表（v1.1 換成學校用品；萬聖節版原圖 `work/gen/skills-halloween.png`）、粉筆標題字：GPT 生（`zsh tools/prompts.sh [名稱]`，原圖在 `work/gen/`，`python3 tools/convert.py` 轉成 `art/*.webp`：洋紅底去背、4×4 圖示表切成每格 128 的圖集）
- `tools/gen.sh` 從**這次 codex 的 session 資料夾**拿圖：原本「拿最新的檔」在別的專案同時生圖時會拿錯（禮堂背景第一次拿到別人的像素房子）；stdin 一定要接 `/dev/null`，不然在背景跑會一直卡在「Reading additional input from stdin」
- 升級卡、提示、結算「聯絡簿」：沿用救救小編的作業簿紙 `art/ui-paper.webp`；按鈕、暫停：木框黑板 `art/ui-board.webp`
- 主畫面圖示 `icon-*.png`：小編原本的正面圖（Vision 去背）＋遊戲夜空＋南瓜燈圖示＋木框，不另外畫
- 3D：小編 `bian_walk/jog`、兔兔老師 `tu_walk`、校長 `zhang_walk`、針筒超人 `needle_walk/jog` 從《下班先鬥牛》複製；側面 3/4 角度、不拉近特寫；勝利播招牌動作、失敗踉蹌
